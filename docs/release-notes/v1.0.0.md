# Apeos 1.0.0

First public release. Two macOS apps for FUJIFILM Apeos and ApeosPort multifunction
printers, built from one shared core, in a single notarised zip.

**[Documentation](https://tony-nz.github.io/ApeosManager/documentation.html)** ·
**[Overview](https://tony-nz.github.io/ApeosManager/)**

## Apeos Manager — for administrators

- **Fleet overview.** Status, toner and drum levels and lifetime counters from every
  printer, with one "needs attention" list gathered across all of them.
- **Users.** The union of accounts across the fleet, showing which printers hold each.
  Create a user on many printers at once; edit membership per printer.
- **Accounting limits.** Per-user copy, print and scan meters in colour and mono, with
  editable caps and counter resets.
- **Permissions.** Feature access per service, accepted login methods, device role,
  permission group, and the address a user's scans are sent from.
- **Address book.** Per printer and merged fleet-wide, with favourites.
- **Logs.** Job history and the device fault log, per printer and fleet-wide, with
  repeated fault codes counted.
- **Discovery.** Subnet sweep, so printers need not be added by address.

## Apeos Quota — for everyone else

A menu bar app showing one person their own allowance across the fleet. It signs in as
that person and never holds an administrator credential.

- Pages remaining on the meter closest to running out, in the menu bar.
- A popover with every meter, a pop-out balance window, and a detail window giving each
  printer's own standing.
- Fleet totals that add up usage and treat an uncapped printer as uncapping the type,
  rather than inventing a huge but finite allowance from the device's sentinel value.
- Partial results are marked partial. An unreachable printer costs its own numbers, not
  the refresh, and is named rather than quietly dropped.

## Demonstration mode

Both apps contain a fictional fleet of five printers and nineteen accounts, covering one
of every state they distinguish. Launch either with `-demoMode YES`:

```sh
/Applications/Apeos\ Manager.app/Contents/MacOS/ApeosManager -demoMode YES
/Applications/Apeos\ Quota.app/Contents/MacOS/ApeosQuota     -demoMode YES
```

A demo run contacts nothing on your network, reads no credential from your keychain and
writes nothing to your settings.

## Notes

- macOS 14 or later. Universal — Apple silicon and Intel.
- Signed with a Developer ID certificate and notarised by Apple.
- Both apps talk only to the printers you configure. No account, no telemetry, no update
  check, no external service.
- Not affiliated with or endorsed by FUJIFILM Business Innovation. The device API is not
  published by the vendor; it was derived by observation and verified against hardware.
