# Apeos 1.0.2

Printers stay signed in, and paper levels now appear alongside toner. If you have been
retyping administrator passwords, this release is for you. Your saved passwords carry
over, so there is nothing to enter again after upgrading.

**[Documentation](https://tony-nz.github.io/ApeosManager/documentation.html)** ·
**[Overview](https://tony-nz.github.io/ApeosManager/)**

## Added

- **Paper tray levels wherever toner is shown.** Levels appear on the fleet cards, on a
  printer's Overview tab, in the menu bar panel, and as a column on the Trays tab. Trays
  a printer cannot measure are left out of the overviews rather than shown as empty.

## Fixed

- **A printer that was briefly unavailable no longer stays signed out.** If a printer was
  asleep or unreachable at the first attempt, the app showed Sign In until it was quit,
  even with a saved password. It now tries again the next time you open a screen for that
  printer or refresh.
- **Expired sessions are renewed.** When a printer rejects a request, the app signs in
  again once and repeats the request.
- **A rejected password is not retried.** If a printer refuses the saved password, the app
  asks you to sign in rather than repeating it, which could lock the account. Signing out
  also stays signed out.
- **A password that could not be saved now says so.** "Remember in keychain" could fail
  silently, and a failed save could lose the password already stored. Saving now updates
  the existing entry, and you are told if macOS refuses.
- **Fewer keychain prompts.** Each saved password is read once when a printer is opened,
  where it could previously prompt twice.
- **The Trays tab no longer crashes.** Trays that shared a number, such as the bypass and
  the first cassette, could bring the table down.
- **Tray levels and paper colours read correctly.** Levels were always blank on real
  devices, and the colour column showed "—" on every printer.

## Notes

- macOS 14 or later. Universal — Apple silicon and Intel.
- Signed with a Developer ID certificate and notarised by Apple.
- Both apps talk only to the printers you configure. No account, no telemetry, no update
  check, no external service.
- Not affiliated with or endorsed by FUJIFILM Business Innovation. The device API is not
  published by the vendor; it was derived by observation.
